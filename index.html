📱 afc2-setup-killer

A minimal, open-source Bash toolchain created by RetroHackLab to disable the stock setup assistant on legacy iOS devices using native AFC2 connections over USB.

⚠️ Educational Purposes Only: This software is designed strictly for academic research and legacy device preservation. It does not bypass remote server-side activation locks. Use at your own risk.

📊 System Requirements

  • Hardware: A5 to A9 Devices (iPhone, iPad, iPod Touch)
  • Firmware: iOS 7.0 minimum up to iOS 9.3.4 iOS 9.3.5 is NOT supported
  • Prerequisite: Device must be jailbroken with Apple File Conduit "2" (AFC2) active.

🚀 Step-by-Step Bypass Instructions

    ./install_deps.sh

    ./fix_format.sh
  • 3 Connect Hardware: Hook up your target jailbroken device via a stable USB cable. Ensure the machine detects the active connection.
  • 4 Execute Bypass: Run the automated deployment payload script to rename the runtime environment targets: 
    ./run_bypass.sh
  • 5 Final Verification: The script will automatically trigger a clean hardware reboot. Upon boot, the software will output:
    [+] Bypass & iCloud Bypass Successfully!
